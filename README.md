# 🐝 Worker Bee

**NYT Spelling Bee Companion**

Worker Bee is a companion tool that makes solving the NYT Spelling Bee quicker and more straightforward. It doesn't give you the answers; instead, it provides a built-in dictionary lookup and tracks your grid and two-letter progress all in one place, so you can focus on the joy of solving.

![Worker Bee UI Preview](og-image.png)

## 🌟 Features
* **Grid & Two-Letter Tracking**: Paste the NYT daily hints and automatically track how many words of each length and starting letter you still need to find.
* **Smart Dictionary Lookup**: Use constraints to filter through valid words that contain only the letters of the day.
* **Auto-Calculations**: As you paste or type in the words you've found, Worker Bee instantly recalculates your remaining grid and two-letter counts.
* **Bingo & Queen Bee Tracking**: See exactly when you hit Bingo or Queen Bee milestones.
* **Zero Backend**: Fully runs in the browser, making it incredibly fast and completely private.

## 🚀 How to Use
1. Open the [NYT Spelling Bee Hints](https://www.nytimes.com/crosswords/spelling-bee-forum.html) page.
2. Copy the entire hints section (from "Spelling Bee Grid" down through the two-letter list).
3. Paste it into the Worker Bee app and click **Load Hints**.
4. Start entering the words you've found in the input box. Worker Bee will cross them off your grid automatically!
5. Use the **Look up** feature to query remaining words if you get stuck.

## 🛠️ Tech Stack
* HTML5
* CSS3
* Vanilla JavaScript (ES6+)
